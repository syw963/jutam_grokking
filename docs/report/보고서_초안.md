 ◦ 지연은 표의 각 칸을 여러 데이터에서 반복해서 본 횟수(칸당 관찰 수)가 많을수록 짧았다. 두 연산을 합친 규칙은 같은 꼴이되 약 2배의 데이터가 필요했다.

## 1. 탐구배경 및 동기

□ 예비 관찰: AI는 "알면서도 틀린다"
 ◦ 이웃한 두 수를 더하는 수열 규칙을 학습시키며 학습 데이터 일부에 일부러 오답을 섞었다(5~20%).
  - 처음 보는 문제는 99~100% 맞혔다. 규칙을 깨친 것이다.
  - 그런데 오답이 달린 학습 문제를 다시 내면 외운 오답을 100% 그대로 냈다. 20만 step을 더 학습해도 바뀌지 않았다.
  - 그 자리에서 원래 정답은 50개 후보 중 2순위(중앙값)로 남아 있었다(우연이라면 약 2%).
 ◦ 한 AI 안에 규칙의 이해와 답의 암기가 함께 있다. 따라서 학습 데이터 정답률만으로는 AI가 외웠는지 이해했는지 알 수 없고, 차이는 처음 보는 문제를 푸는 능력(일반화)에서 드러난다.

□ 암기와 일반화는 시점도 다르다: grokking
 ◦ 신경망은 학습 데이터를 모두 외운 뒤 한참 지나서야 갑자기 일반화하기도 한다(grokking, Power 외, 2022). 【그림 1: grokking 곡선, 본 실험 데이터】
  - 본 실험에서도 학습 데이터 정답률은 300 step에 100%가 되었지만, 처음 보는 문제의 정답률은 약 24,000 step 동안 0%였다가 갑자기 100%가 되었다.
 ◦ 언제, 어떤 조건에서 암기가 일반화로 바뀌는지 알면
  - 필요한 데이터양을 미리 계산해 데이터 수집 비용을 줄이고,
  - 학습 데이터 정답률만 보고 학습을 일찍 멈추는 실수를 피할 수 있다.

□ 탐구 목적
 ◦ 작은 Transformer에 수열 변환 규칙을 학습시켜, grokking의 발생 조건(필요한 데이터 수)과 지연을 정하는 요인을 찾고, 그것을 실험 전에 예측할 수 있는 법칙으로 세운다.
 ◦ 연구문제
  - 연구문제 1(경계): 일반화에 필요한 학습 데이터 수는 무엇으로 정해지는가?
  - 연구문제 2(지연): 암기 후 일반화까지 걸리는 시간은 무엇으로 정해지는가?
  - 연구문제 3(합성): 두 연산을 이어 붙인 규칙도 같은 법칙으로 예측되는가?

## 2. 이론적 배경

□ Transformer와 일반화
 ◦ Transformer는 입력의 각 위치가 다른 위치를 얼마나 참고할지(attention)를 학습하는 신경망 구조로, 현재 대형 언어 모델의 기본 구조이다(Vaswani 외, 2017).
 ◦ 학습 데이터(train)를 맞히는 것을 암기, 학습에 쓰지 않은 데이터(test)를 맞히는 것을 일반화라고 한다. 본 탐구는 train과 test의 숫자 조합이 겹치지 않게 나누어, test 정답률로 일반화를 잰다.

□ grokking
 ◦ Power 외(2022)는 두 수의 덧셈·곱셈(mod p) 표의 일부만 학습시킨 작은 Transformer가 train을 외운 뒤 수천~수만 step 뒤에 갑자기 일반화하는 현상을 보고하고 grokking이라 불렀다.
 ◦ 원인에 대한 설명
  - weight decay(가중치를 조금씩 줄이는 규제)가 있으면, 같은 train 정답률을 더 작은 가중치로 내는 "규칙 회로"가 "암기 회로"보다 유리해져 결국 규칙으로 넘어간다(Nanda 외, 2023; Varma 외, 2023; Liu 외, 2023).
  - 따라서 weight decay가 없으면 grokking이 일어나지 않고, 데이터가 많을수록 규칙 회로가 일찍 이긴다.
 ◦ 필요한 데이터 수: 일정량 이상의 데이터가 있어야 일반화가 일어나는 "임계 데이터 크기"가 보고되었다(Varma 외, 2023; Zhu 외, 2024). 하지만 그 크기가 과제의 어떤 성질로 정해지는지는 정량적으로 알려져 있지 않다.

□ 연산 표와 이 탐구의 관점
 ◦ 이웃 덧셈 규칙에서 출력 한 칸은 "자기 숫자 a와 다음 숫자 b"로 정해지는 덧셈 표의 한 칸 T(a, b)이다. 숫자 범위가 1~n이면
  - a+b(교환법칙 성립)는 순서 없는 쌍이라 표의 칸 수 C = n(n+1)/2 (n=50이면 1,275칸),
  - a+3b(교환법칙 없음)는 순서쌍이라 C = n² (2,500칸).
 ◦ 데이터 하나(숫자 5개)는 덧셈 표의 칸 5개를 보여 준다. 그래서 "표의 크기"와 "각 칸을 몇 번 보았는가"가 학습에 영향을 줄 것으로 보았다. 【그림 2·3: 연구문제 그림 rq1, rq2】

□ 오답(라벨 노이즈)과 grokking
 ◦ Doshi 외(2024)는 덧셈 표 학습에서 일부 정답을 무작위 오답으로 바꾸고, 규제가 약하면 오답 암기와 일반화가 공존하고, 규제가 적당히 강하면 외운 오답을 잊는(역전) 단계가 있음을 보였다(MSE 손실, MLP).

## 3. 탐구과정

□ 과제
 ◦ 입력: 1~50 중 서로 다른 숫자 5개로 된 수열. 출력: 같은 길이 수열. 【그림 4: 과제 그림 task.png】
 ◦ 기본 규칙(이웃 덧셈): 출력 i = 입력 i + 입력 i+1 (마지막은 첫 숫자와). 합은 1~50 범위로 되돌린다((a+b) mod 50 + 1).
 ◦ 비교 규칙: 참조할 칸의 배선 12종, a+3b(교환법칙 없음), 곱셈 a×b, 두 연산 합성(덧셈 두 번, 정렬 후 덧셈), 규칙 없는 무작위 표.
 ◦ train/test 분리: 숫자 조합(집합) 단위로 나누어 같은 조합이 양쪽에 들어가지 않게 했다. test는 2만 개.

□ 모델과 학습
 ◦ 기본 모델: 2층 Transformer(차원 128, 헤드 4, 출력 칸마다 질의 토큰을 두어 5칸을 한 번에 출력).
 ◦ 비교 모델: 큰 모델(4층, 차원 256, 파라미터 약 8배), GPT(앞 출력을 보고 다음 출력을 내는 디코더).
 ◦ 학습: AdamW, 학습률 3×10⁻⁴, weight decay 1.0, 전체 데이터 한 번에(full batch), 최대 6만~20만 step.
  - 예비 실험에서 학습률 10⁻³은 학습이 무너져 3×10⁻⁴로 정했다.
 ◦ 여러 학습을 한 GPU에서 동시에 돌리는 묶음 학습 코드를 직접 작성해 약 3,800회 학습했다(클라우드 GPU 대여).

□ 측정
 ◦ 암기 시점 t_fit: train 정답률(5칸 모두 맞음) 99% 도달 step.
 ◦ 일반화 시점 t_gen: test 정답률 95% 도달 step. 지연 = t_gen − t_fit.
 ◦ 경계 N₀: 같은 조건을 seed 5~10개로 반복해 절반이 일반화하는 데이터 수(이웃 두 점 사이는 로그 보간).
 ◦ 칸당 관찰 수 = 데이터 수 × 데이터 하나가 보여 주는 서로 다른 칸 수 ÷ 표의 칸 수.

□ 탐구 진행과 사전 예측
 ◦ 탐구는 가설 → 실험 → 수정의 순서로 진행했고, 중요한 실험은 결과를 보기 전에 예측을 문서에 적어 두고 비교했다(총 30여 개 예측, 맞은 것과 틀린 것 모두 기록, 【표: 사전 예측 성적표 요약】).
 ◦ 진행 단계
  - 1단계: 규칙의 대칭이 grokking을 정한다는 가설 → 배선 12종, 교환법칙 제거 실험으로 검증(기각).
  - 2단계: "데이터 하나가 주는 서로 다른 칸 수"와 "칸당 관찰 수"로 지연을 설명하고 예측(연구문제 2).
  - 3단계: 표 크기·수열 길이를 바꾸자 관찰 수만으로는 경계가 설명되지 않음 → 필요한 데이터 수의 법칙을 세우고 새 조건으로 사전 예측 검증(연구문제 1).
  - 4단계: 합성 규칙(연구문제 3), 모델 크기·구조·곱셈 연산에서 법칙의 일반성 확인.
  - 5단계: 오답 실험(동기)과 그 원인 확인.

## 4. 탐구결과

□ 4-1. 처음 가설의 기각: 대칭은 grokking을 정하지 않는다
 ◦ 같은 덧셈을 배우는 배선 12종을 비교했다(325회). 배선의 대칭 크기로 묶으면 순서가 뒤섞였고(지연과의 상관 −0.1~−0.3), 데이터 하나가 주는 서로 다른 칸 수(3·4·5개)로 묶으면 깔끔히 정렬되었다(상관 −0.91~−0.93). 【그림 5: F1】
  - 예: 768개에서 서로 다른 칸 5개 배선은 15/15 일반화(지연 4,900), 3개 배선은 0/10.
 ◦ 연산을 a+3b로 바꾸면 대칭은 그대로인데 모든 배선이 서로 다른 칸 5개를 준다. 1,280개에서 a+b는 배선마다 지연이 18배 달랐지만(100~1,800), a+3b에서는 5,550~6,800으로 모였다(200회). → 대칭 가설 기각. 【그림 6: F2】

□ 4-2. 연구문제 1: 필요한 데이터 수는 연산 표의 크기로 정해진다
 ◦ 표 크기(n = 23~101)와 연산(a+b, a+3b)을 바꾼 9개 조건의 경계가 하나의 식에 ±10% 안으로 놓였다. 【그림 7: F8】
  - N₀ ≈ 2.81 × C^0.764 (C: 연산 표의 칸 수). 표가 2배 커지면 필요한 데이터는 약 1.7배.

| 연산 | n | 칸 수 C | 실측 경계 | 법칙 |
|---|---|---|---|---|
| a+b | 23 | 276 | 211 | 206 (사전 예측) |
| a+b | 31 | 496 | 329 | 322 |
| a+b | 50 | 1,275 | 625 | 662 |
| a+b | 61 | 1,891 | 882 | 895 |
| a+b | 71 | 2,556 | 1,183 | 1,127 |
| a+b | 101 | 5,151 | 2,067 | 1,925 (사전 예측) |
| a+3b | 31 | 961 | 534 | 534 |
| a+3b | 41 | 1,681 | 829 | 818 |
| a+3b | 50 | 2,500 | 995 | 1,108 |

 ◦ 사전 예측 검증
  - n=23: 관찰 수 가설은 약 130개, 데이터 수 법칙은 약 220개를 예측했다. 실제는 130~190개 0/10, 220개 7/10, 260개 10/10으로 법칙이 맞았다.
  - n=101(예측 약 2,370 → 실측 약 2,070), 수열 길이 4(650개 근처 50% → 650개 9/10, 550개 1/10), 수열 길이 6(800개 이상 성공 → 10/10)도 맞았다.
 ◦ 수열 길이(2~6)가 달라도 같은 표에서는 경계가 약 600~800개로 모였다.
 ◦ 한계: 출력 일부만 학습시켜 데이터 개수만 늘리면 효과가 없었고, 데이터 안에서 같은 칸이 반복되는 배선은 더 어려웠다. 법칙의 "데이터"는 모든 출력이 학습되는 데이터이다.

□ 4-3. 연구문제 2: 지연은 칸당 관찰 수로 정해진다
 ◦ 서로 다른 칸 3·4·5개의 a+b와 a+3b가 칸당 관찰 수 하나로 한 곡선에 모였다(지연과의 상관 −0.93; 표를 얼마나 넓게 보았는지(coverage)는 −0.33). 관찰 수가 0.4회 늘 때마다 지연이 약 절반. 【그림 8: F3】
 ◦ 이 곡선으로 새 조건 24개의 지연을 실험 전에 예측했고, 관찰 수 2.6~3.4에서 평균 1.1배 오차로 맞았다(280회).
 ◦ 넓게보다 반복해서: 데이터 수를 고정하고 데이터 구성만 바꿔 표를 덜 넓게 보게(같은 칸을 반복) 하자 오히려 빨라졌다. 【그림 9: F4】
  - 768개: coverage 0.944 → 지연 6,900, 0.882 → 3,700, 0.842 → 2,950.
 ◦ weight decay는 지연의 크기를 바꾸지만(약 1/wd, wd 0이면 일반화 없음) 관찰 수에 따른 순서는 모든 설정에서 유지되었다.
 ◦ grokking(긴 지연)은 경계 바로 위에서만 나타나고, 데이터가 충분하면 외우자마자 일반화했다.

□ 4-4. 연구문제 3: 합성 규칙은 같은 꼴이되 약 2배의 데이터가 필요하다
 ◦ 정렬 후 덧셈: 부품보다 1.5~2배(약 1,300~2,000개)가 필요했다(사전 예측 적중).
 ◦ 덧셈 두 번(x_i + 2x_{i+1} + x_{i+2}): 두 번 나눠 배우지 않고 세 값의 표로 동작했다. 경계는 n=19에서 약 2,940개, n=23에서 약 4,900개로 법칙의 약 2.0·2.2배였고, 두 표 사이 비율은 C^0.76 꼴과 맞았다.
 ◦ 전체 데이터 학습과 미니배치 학습 사이에 차이가 없었다.

□ 4-5. 법칙의 일반성: 모델과 연산을 바꿔도 같은 꼴
 ◦ 모델 크기·구조와 연산을 바꿔 다섯 가지 표 크기에서 경계를 다시 쟀다(684회).

| 바꾼 것 | 지수 (기본 0.764) | 필요한 데이터 (기본 법칙 대비) |
|---|---|---|
| 큰 모델(파라미터 약 8배) | 0.75 | 0.88~0.97배 |
| GPT(디코더 구조) | 0.73 | 2.7~3.1배 |
| 곱셈 a×b (n 소수) | 0.85 | 0.66~0.86배 |
| 곱셈 a×b (n=50, 합성수) | — | 약 0.5배 |

 ◦ 표가 클수록 데이터가 더 필요하다는 꼴은 모두 유지되었다.
  - 모델을 8배 키워도 필요한 데이터는 거의 같았고(약 7% 감소), 구조가 다른 GPT는 약 3배가 필요했다 → 모델 크기보다 구조가 중요하다.
  - 같은 표 크기라도 곱셈 mod 50(합성수)은 같은 크기의 소수 표(n=47·53)보다 확실히 쉬웠다. 결과값이 고르게 퍼지지 않아(0이 되는 칸이 약 2배) 표가 실제로는 단순하기 때문으로 보인다 → 표의 구조도 상수에 영향을 준다.

□ 4-6. 학습은 단계적으로 일어난다 (탐색적 관찰)
 ◦ 200 step 간격으로 모델을 저장해 분석했다(14개 학습). 【그림 10: F5】
  - 데이터를 통째로 외움(학습에 나온 칸조차 다른 데이터에서는 못 맞힘) → 학습에 나온 칸을 맞힘 → 나오지 않은 칸까지 맞힘(일반화). 14/14 학습에서 같은 순서였다.
  - 규칙이 없는 무작위 표는 처음부터 칸 단위로 외웠다. → 지연은 "칸 단위로 배우는 것이 어려워서"가 아니라, 구조가 있는 표에서 처음 택한 통째 암기 방식에서 벗어나는 데 걸리는 시간으로 보인다.

□ 4-7. 오답 실험: 규칙을 깨친 뒤에도 외운 오답은 남는다
 ◦ 같은 과제에서 학습 데이터의 5~20%에 오답을 섞었다(데이터마다 한 칸, 또는 같은 칸에 일관된 오답, 20만 step, 195회). 【그림 11: E30_noise_curves】
  - 처음 보는 문제는 99~100% 맞히면서, 외운 오답은 20만 step과 weight decay 2배에서도 100% 유지되었다.
  - 원래 정답은 2순위(중앙값)로 남았다(2순위 비율 57~84%, 우연 약 2%).
  - 데이터가 많으면 규칙을 먼저 배우고 오답을 나중에 외웠다. 데이터가 적으면 오답까지 먼저 외우고 한참 뒤 일반화했다.
  - 오답은 칸 단위로 번졌다: 데이터마다 흩어진 오답은 처음 보는 문제로 번지지 않았고(8% 이하), 같은 칸에 일관된 오답은 번졌다(최대 99%).
 ◦ 선행연구(Doshi 외, 2024)와 달리 오답을 잊는 단계가 나타나지 않아 원인을 확인했다.
  - 두 수 과제(입력이 곧 표 한 칸)로 바꿔도 외운 오답은 100% 유지되었다 → 문맥 때문이 아니다.
  - 【E36 결과: 손실 함수를 MSE로 바꾸면 오답을 잊는지 — 결과 나오면 작성】

## 5. 결론 및 제언

□ 결론
 ◦ grokking의 경계와 지연을 정하는 것은 규칙의 대칭이 아니라, AI가 배워야 할 연산 표의 크기와 학습 데이터가 그 표를 얼마나 반복해서 채우는가이다.
  - 연구문제 1: 일반화에 필요한 데이터 수는 표의 칸 수로 정해진다(N₀ ≈ 2.8 × C^0.76, 9개 조건 ±10%). 새 조건의 결과를 실험 전에 예측해 맞혔다.
  - 연구문제 2: 지연은 칸당 관찰 수가 많을수록 짧고, 표를 넓게 보는 것보다 같은 칸을 반복해서 보는 것이 중요하다.
  - 연구문제 3: 합성 규칙도 같은 꼴을 따르되 약 2배의 데이터가 필요하다.
 ◦ 이 법칙의 꼴은 모델 크기·구조와 연산(곱셈)을 바꿔도 유지되며, 상수만 모델 구조(GPT 약 3배)와 표의 구조에 따라 달라진다.
 ◦ 규칙을 깨친 AI도 학습 데이터의 오답은 그대로 외워 두며, 원래 정답을 2순위로 갖고 있다. 이해와 암기는 한 모델 안에 공존한다.

□ 의의
 ◦ grokking의 필요한 데이터 수를 과제의 성질(표 크기)로 계산하는 식을 세우고, 실험 전 예측으로 검증했다. 맞은 예측과 틀린 예측을 모두 기록해 가설이 바뀐 과정을 투명하게 남겼다.

□ 제언
 ◦ 활용
  - 규칙이 배워야 할 표의 크기만 알면 필요한 학습 데이터 양을 미리 계산해 데이터 수집과 학습 비용을 줄일 수 있다.
  - 데이터가 경계 부근이면 암기 후 한참 뒤에 일반화가 일어나므로, 학습 데이터 정답률만 보고 학습을 멈추면 안 된다.
  - 학습 데이터의 오류는 오래 학습해도 지워지지 않을 수 있으므로, 학습 전에 데이터를 정제해야 한다.
 ◦ 후속 연구
  - 지수가 1보다 작은 이유(큰 표일수록 칸당 필요한 데이터가 적음)를 표의 구조와 연결해 설명할 필요가 있다.
  - 더 큰 모델과 실제 언어 데이터에서도 같은 꼴의 법칙이 성립하는지 확인할 필요가 있다.
  - 【E36 결과에 따라】 외운 오답이 지워지는 조건(손실 함수, 규제 세기)을 밝힐 필요가 있다.
 ◦ 한계
  - 작은 모델과 숫자 수열 과제에서 얻은 결과이다. 조건당 반복은 5~10회로 경계 근처는 흩어짐이 있다.
